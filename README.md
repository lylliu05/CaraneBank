# CaraneBank 排班管理系统

纯前端静态实现的排班管理系统，无需后端与数据库，数据保存在浏览器本地存储（LocalStorage）。

## 功能

- **排班日历**：按月视图展示排班，点击格子即可设置班次；同一班组共用同一套排班，支持一键按规则排满整月
- **排班模式**：自定义班次类型（如白班、夜班、休息），每种班次对应一个色块
- **班组**：将人员归入班组，日历按班组分组展示，可配置轮班规则
- **人员**：管理排班人员及其所属班组
- **导出**：导出本月排班表（CSV）、备份全部数据（JSON）

## 技术栈

- 纯 HTML + CSS + JavaScript，无任何第三方依赖
- 单页应用（Hash 路由）
- 数据持久化：浏览器 LocalStorage

## 使用方式

直接打开 `index.html` 即可使用，或部署到任意静态托管平台（GitHub Pages、Vercel、Nginx 等）。

## 项目结构

```
├── index.html      # 页面结构
├── styles.css      # 样式

```

## 数据说明

所有数据保存在当前浏览器本地存储中，更换设备或浏览器不会共享数据；建议定期使用「导出 → 备份全部数据（JSON）」进行备份。
